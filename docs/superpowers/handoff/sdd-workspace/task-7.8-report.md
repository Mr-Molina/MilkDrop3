## How 7.9 wires it
- Messages: `CustomMessages::launch(n, &mut rng, now)` -> `TitleLaunch`; `SuperTextSlot::start(&launch)` (kill on Ctrl+T/Ctrl+Y/Delete: `kill()`); give the renderer `launch.st` via `Renderer::supertext_mut()`, with text and font = `launch.text/face/bold/ital`. Song title: `TitleLaunch::song_title(..)` through the same slot (renderer's `start_song_title` already exists). GAP: md-render's `render_title_texture` only has the song-title branch; the custom branch (font search with `fit_font_px` over a measure closure using md-text layout, then draw centred) must be added in md-render (a small follow-up or part of 7.9), because md-render cannot call into md-core. Everything it needs (table, band, display text, algorithm) is in `supertext.rs`.
- Sprites: build `Sprites::new(Ini, plugin_dir, global)` sharing the presets' `Rc<RefCell<GlobalMem>>`; keys 0-9 in sprite mode call `launch(n, &mut StoreTextures{gpu, store}, now, frame)` and route `toasts` to `ui.add_error(msg, duration, category, bold, now)`; each frame `tick(&SpriteInputs{..})`, `frames: Vec<_> = ticked.iter().map(|t| t.frame())`, `renderer.draw_sprites(ctx, &frames)`, then `reap(&mut StoreTextures{..})`.
