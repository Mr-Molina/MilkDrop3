#### Important
1. text_draw.rs:152-180 `layout_all`: the retry is dead code. `gens[font]` is overwritten after every item (:168), and an atlas only changes while laying out its own font, so `generation() == gens[font]` (:175) is always true. When a later item grows (md-text atlas.rs:282, initial 256 px -> common on first menu/help/preset-list frame) or resets the atlas, earlier items of the same font keep UVs from the old generation and sample wrong texels for that frame. Fix: record the generation per item at layout time (or the first gen per font) and re-lay out if any item's differs from the final; add a test that forces growth (e.g. large size_px, several items of one font).
2. text_pass.rs:160 `draw_box` / text_draw.rs:210, :231: draw_box is opaque (BlendMode::Off) and queue-ordered (test tests/text.rs:152 pins "later box covers earlier text"), mirroring CTextManager::DrawBox, which has no external caller. The C++'s caller-facing box is DrawDarkTranslucentBox (see ❌ above): alpha-blended SRCALPHA/INVSRCALPHA with 0xD0000000 and drawn beneath all queued text of the frame — exactly the brief's "boxes before text". As shipped, 7.7 cannot reproduce menus, help, preset list, tooltip or playlist backgrounds (they would be opaque, and cover earlier-queued corner text). Fix: keep `draw(.., dark_box)` as is (bBox: opaque, swapped before its text); make `draw_box` the translucent box: blended (BlendMode::Alpha, fixed_color, colour as given), recorded in a layer drawn before every queued message of the frame; replace later_box_covers_earlier_text with a test that a draw_box queued after text stays under it and blends (e.g. 0xD0 black over a non-black composite).
